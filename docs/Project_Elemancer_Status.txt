## 1. Codebase Implementation (COMPLETED)
The **Elemancer** class has replaced the Bard (ID 11) with a fully functional elemental mechanic set.

### **Core Mechanics**
*   **Manifestations:** Replaced "Songs" with sustained elemental rites (Pulse-based).
*   **Geomancy:** Passive skill. Reduces Manifestation cost by 20% if standing in a matching sector (e.g., Magma in Mountains).
*   **Ley-Sluicing:** Passive skill. Reduces movement cost by 50% and grants immunity to exhaustion-based movement stops.
*   **Terraform:** Active skill. Temporarily alters the player's effective sector type to trigger Geomancy bonuses.

### **Key Files Modified**
*   `src/lib/general/class.c`: Renamed class, added `ITEM_ANTI_ELEMANCER` logic.
*   `src/lib/magic/sing.c`: Core Manifestation logic, Geomancy checks, Terraform implementation.
*   `src/lib/actions/movement.c`: Ley-Sluicing logic (exhaustion bypass).
*   `src/lib/actions/other.c`: `do_practice` refactored to allow Elemancer self-practice in safe rooms.
*   `src/lib/magic/spells.c/h`: Registered new spell IDs (296-298, 351-359).
*   `sys/text/help/help.hlp`: Comprehensive help entries added.

### **Migration Tools**
*   `src/bin/binaries/elemancer_migrate.c`: C utility to update binary player/locker files (Adds `!ELEMANCER` flag to `!THIEF` items).
*   `update_obj_files.py`: Python script to update world `.obj` text files (Already executed).
*   **Guide:** `docs/Elemancer_Migration_Guide.txt` contains full instructions for Prod deployment.
